## ⚙️ How to Run the Programs

1. Install a C++ compiler, such as GCC, or use an IDE that supports C++.
2. Clone this repository:

   ```bash
   git clone https://github.com/Rakesh-star1234/DSA-CPP.git
   ```

3. Open the repository in your preferred code editor.
4. Navigate to the required `.cpp` file.
5. Compile and execute the program.

Example using GCC:

```bash
g++ Main.cpp -o Main
```

On Windows PowerShell:

```powershell
.\Main.exe
```

*Replace `Main.cpp` with the relevant source filename when running another program.*
