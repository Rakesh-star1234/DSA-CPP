## 💻 How to Run

1. Install a C++ compiler, such as GCC, or use an IDE that supports C++.
2. Clone this repository:

   ```bash
   git clone https://github.com/Rakesh-star1234/DSA-CPP.git
   ```

3. Open the required `.cpp` file.
4. Compile and run it using your compiler.

Example using GCC:

```bash
g++ Main.cpp -o Main
```

On Windows PowerShell, run:

```powershell
.\Main.exe
```
